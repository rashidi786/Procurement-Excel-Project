\# Phoenix Enviro Tech – Procurement Analytics Project



\## Project Overview



This project focuses on analyzing procurement operations at Phoenix Enviro Tech using Microsoft Excel. The objective is to transform raw procurement data into meaningful business insights that can help management monitor purchasing activities, evaluate vendor performance, control costs, and improve procurement efficiency.

\## Project Objectives



\- Analyze purchase orders and procurement spending.

\- Evaluate vendor performance and purchasing patterns.

\- Analyze material-wise and project-wise expenses.

\- Monitor delivery and invoice information.

\- Identify important trends and areas for improvement.

\- Support management decision-making through data analysis and dashboards.



\## Tools \& Technologies



\- Microsoft Excel

\- Excel Formulas and Functions

\- Data Cleaning

\- PivotTables

\- PivotCharts

\- Interactive Dashboards

\- Data Analysis and Visualization



\## Dataset Description



The project uses procurement-related datasets covering:



\- Vendors

\- Materials

\- Projects

\- Employees

\- Purchase Orders

\- Deliveries

\- Invoices



The datasets are used to perform procurement analysis and generate meaningful business insights.

This project demonstrates how Excel can be used to analyze procurement data, identify spending patterns, evaluate purchasing activities, and present findings through interactive dashboards. The analysis can help management make more informed and data-driven procurement decisions.



\## Conclusion



The Phoenix Enviro Tech Procurement Analytics Project demonstrates practical data analysis skills using Microsoft Excel, from working with raw datasets to developing dashboards and communicating business insights.
